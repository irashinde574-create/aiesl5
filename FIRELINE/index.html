How to use FIRELINE

  1. Place occupant — click any safe walkable cell.
  2. Choose mode — Fire first, or fire spreading during evacuation.
  3. Start fire or run — individual methods or Compare All.
  4. Watch adaptation — routes update as cells become unsafe.

Educational grid model only; not a life-safety tool or physically accurate fire/smoke simulation.
